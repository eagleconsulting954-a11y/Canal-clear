Enterprise-grade encryption. Your OCEANS-X API key is encrypted before storage using AES-256-GCM. Only you can access it — CanalClear staff cannot read your key. The key is used solely to pull vessel data from MPA's OCEANS-X API to enrich your Malacca filings.
About MPA OCEANS-X: The Maritime and Port Authority of Singapore's OCEANS-X platform (launched Jan 2026, successor to SG-MDH) provides vessel particulars, arrival records, and position data for Singapore port calls. Register for an API key at oceans-x.mpa.gov.sg. The API is free for commercial maritime operators.
Register at oceans-x.mpa.gov.sg → API Access → Request Key. AES-256-GCM encrypted on save — never stored in plain text.

How MPA Integration Works
OCEANS-X enrichment + digitalPORT@SG pre-arrival notification
1
Connect your OCEANS-X API key Add your MPA OCEANS-X API key here — CanalClear uses it to pull verified vessel data from Singapore's maritime registry
2
Auto-enrich Malacca filings with MPA data When you enter an IMO number on the Malacca filing form, CanalClear queries OCEANS-X to pre-populate vessel name, flag, tonnage, dimensions, and Singapore port call history
3
Click "Submit to MPA" on the filing export panel CanalClear generates a complete digitalPORT@SG Pre-Arrival Notification (PAN) package with MPA reference number and audit log entry
4
Upload to digitalPORT@SG portal CanalClear guides you through the digitalPORT@SG online form submission. Direct API submission available when MPA partner agreement is in place.
5
Track all submissions with audit trail Every MPA submission logs an MPA reference number, timestamp, and vessel data in CanalClear's filing audit log
