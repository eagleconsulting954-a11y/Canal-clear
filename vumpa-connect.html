About VUMPA Automated Submission

The ACP VUMPA portal (www.vumpa.gob.pa) uses a web form interface with no public API. Automated submission via browser automation (RPA) is in development.

Current approach: CanalClear generates a structured VUMPA filing package from your form data. You or your ship agent uploads this to VUMPA directly. Your submission is tracked in the history above with an ACP reference number.

Large shipping lines with private EDIFACT/XML agreements with ACP can continue to use those channels. CanalClear supports the standard web form workflow for operators without private agreements.
